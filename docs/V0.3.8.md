This follow-up implements the user's corrections to the v0.3.7 candidate. Existing thumbnail repairs, system volume handling, channel seeking, USB navigation and widgets are retained.

## Player and Media

The five centered controls are **Previous Episode / −10 / Play-Pause / +10 / Next Episode**. Previous mirrors the Next icon and changes episodes; it no longer exits the player. Samsung Back still returns to the folder. Button skips remain exactly ten seconds; channel and timeline D-pad skips remain thirty seconds.

Time is right-aligned above the progress bar's right end. Focusing the timeline leaves the bar's container without a border, outline, shadow or background; only the circular thumb gains a blue border. The black Play/Pause focus outline remains.

Media uses the selected wallpaper's bundled preblurred image across the full screen, with a lighter dark overlay for readable labels. No live backdrop filter was added. The wallpaper still hides during AVPlay so the native video plane remains visible. Opening Media while the first USB directory is arriving now assigns focus after the cards mount, avoiding a discovery/navigation timing race.

## Bitcoin

As explicitly selected by the user, Bitcoin replaces the disconnected Calendar card in the default **Weather / Bitcoin / World Clock** row. The three-widget maximum is preserved. The unchanged old default trio migrates once; custom and empty selections are preserved, and Calendar can still be selected in Widgets settings.

The card includes BTC/USD price, percentage change since midnight in the main clock's selected timezone, a shaded daily SVG graph, 24-hour high/low and Coinbase volume in BTC. Enter opens a larger graph and stats panel. Up from the dock reaches the widgets; Back restores widget focus.

Data comes directly from Coinbase's public [product stats](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-stats) and [candles](https://docs.cdp.coinbase.com/api-reference/exchange-api/rest-api/products/get-product-candles) endpoints. No account or API key is used. Five-minute candles provide the local-day chart; 24-hour high/low/volume are explicitly labelled as exchange statistics rather than all-market totals. Today's opening price comes from the first candle at local midnight, never from the rolling 24-hour open. Missing opening data produces a dash rather than a fabricated percentage.

Refresh runs at most once per five minutes while Home is active, pauses when hidden or during playback, and has an eight-second request bound. A single small versioned cache survives restart; saved data displays its date/time and a Saved label. Invalid, future-dated, oversized, mismatched-timezone or more-than-three-day-old caches are discarded. Earlier-day charts are not presented as today's graph.

Live Coinbase requests returned HTTP 200 with browser-compatible CORS, and the actual mapper accepted 243 daily graph points during validation. [Raw live responses](../artifacts/v038/live-market-input.json) and [mapped snapshot](../artifacts/v038/live-market-snapshot.json) are local evidence. UI screenshots use deterministic test prices and are not current price quotes.
