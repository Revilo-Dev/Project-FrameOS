## Implemented behavior

- Samsung AVPlay owns one native player. A selected video is resolved again in read mode, its native `file:///` URI is validated and decoded once to an absolute device path, then opened, prepared asynchronously and displayed in a 1920×1080 logical rectangle with aspect ratio preserved. MP4/MKV are recognised case-insensitively; codec support is determined by the TV, not the filename extension.
- Fullscreen overlays show the original filename, Back, timeline/time, Previous, Play/Pause/Replay and Play Next. The timeline seeks ten seconds with Left/Right. Controls fade after four idle seconds while playing, remain visible while paused/preparing/buffering, and the first directional/Enter input reveals hidden controls without activating them. Only documented media keys are registered while the player is open. Samsung Power/Home/Volume/Exit are untouched.
- Preparation and seeking are serialized. Back, USB removal and file changes clean up AVPlay; cleanup during an asynchronous operation waits for its real callback before issuing SDK commands. Stale callbacks cannot replace newer state. Preparation/seek timeouts show an error. If a native operation never calls back, the controller keeps the gate closed rather than making prohibited overlapping calls; reopening FrameOS may be necessary on that firmware.
- Episode labels support Episode/Ep/E, SxxExxx and season×episode patterns. Seasons/episodes sort numerically; ambiguous ranges, resolution/year/codec numbers and random numerical filenames retain their original names. Next prefers the current detected series when at least two entries match; otherwise it uses natural filename order in the same folder and drive. Hidden items are excluded unless Show Hidden Files is enabled. Next is disabled at the end; automatic next playback is not enabled.
- Focused video titles appear in a fixed two-line region above the grid without metadata reads or grid movement. Extremely long titles are clipped after two lines; the original filename remains in the accessible name, tooltip, Details and wrapping player title. Cards use 16:9 thumbnail regions and concise episode labels. Two rendered rows limit DOM work to 12 cards (8 in compact preview); remote arrows and wheel paging reach the full directory.
- Thumbnails query existing `tizen.content.find` metadata by the exact content URI and read `thumbnailURIs`. No media scanner, decoder, transcoder or hidden video element is created. At most two native queries and 24 queued jobs run, only for visible cards; obsolete view results are ignored. The bounded 128-item cache stores URI metadata only, with a one-day positive/five-minute negative lifetime. Native database errors, absent indexing, inaccessible images and unsupported APIs use the same deterministic video placeholder. A hung/permission-denied native index disables further queries for the session. USB removal invalidates that drive's cache.
- Hold OK/Enter for 750ms to open Hide/Unhide, Details and Cancel. Short Enter opens only after release; a completed hold does not also click. **Options** opens the most recently focused tile's menu as a remote fallback; Context Menu/Shift+F10 and right-click also work. These actions only change local FrameOS preferences, never USB files. Show Hidden Files persists, restores sorted positions and marks hidden entries. Restoring an item inside a hidden folder also restores its hidden ancestors, as the menu explains.
- Hidden identities combine the native storage label and relative path, distinguishing matching filenames in different folders/drives. **Limitation:** Tizen filesystem discovery exposes labels, not a persistent hardware UUID. A remapped label can lose association; a different drive reusing the same label/path can inherit preferences. Hide is a convenience preference, not access control. No destructive USB action is exposed.
- The Settings dock shortcut has its icon, focus treatment and accessible name “Settings”, with no visible label or empty label spacing. New Beith is selectable alongside Brisbane. Coordinates `-27.766, 152.942`, timezone `Australia/Brisbane`, were verified against [Open-Meteo geocoding result 8348547](https://geocoding-api.open-meteo.com/v1/search?name=New%20Beith&count=10&language=en&format=json&countryCode=AU). City selection, per-city weather caches and offline behavior are preserved; no device geolocation is used.

The supplied 47 wallpapers/icons/logo, clock format/time-zone settings, hourly weather, themes, animation settings, FPS counter, same-page Home/Media transition, USB diagnostics and existing app integration notices remain available.

## Exact deployment and acceptance steps

Only after approval to install:

```powershell
Set-Location 'C:\Users\revil\StudioProjects\frameos\Project-FrameOS'
& 'C:\samsungdev\tizen-studio\tools\sdb.exe' connect '192.168.0.23:26101'
npm run check:tv
npm run deploy:tv
```

`deploy:tv` rebuilds, stages only managed frontend files, builds/signs/verifies, installs and launches using the unchanged application ID and existing matching profile. It stops on any failed step. Do not uninstall or replace certificates to work around an author mismatch. To prepare another signed package without touching the TV or external frontend, use `node scripts/tv.mjs package`.

1. In **Settings → USB diagnostics → Rescan USB**, confirm runtime, filesystem API and read privilege are Yes; the drive is EXTERNAL/MOUNTED and real root entries appear. Record any native error name/message.
2. Down from Home opens Media Hub. Enter a nested folder containing MP4/MKV files; verify episode order, full focused title, original filenames in Details and Back focus restoration.
3. Select an MP4, then an MKV. Confirm actual video and audio, fullscreen aspect ratio, Pause/Resume, timeline ±10 seconds, physical media keys, Previous/Next and end-of-list state. Wait four seconds to check overlay hiding, then reveal it with an arrow. Test one unsupported file for an honest error.
4. Hide a file with long OK and with Options; enable Show Hidden Files, Unhide, and restart to check persistence. Confirm USB names/data remain unchanged. Repeat with a folder. Check Next skips hidden videos when the toggle is off.
5. Remove USB during playback and during a seek. The player must leave safely for the disconnected Media Hub without closing FrameOS. Reinsert and browse again. Inspect indexed thumbnails if the TV provides them; a placeholder is expected when it does not.
6. Confirm New Beith weather, Brisbane, clock format/time zone, all wallpapers, themes, motion controls and app shortcuts still work. No firmware, system settings or automatic startup changes are part of this release.
